Diseño de Bases de Datos¶

Del enunciado de un cliente al modelo relacional normalizado: diagramas entidad/relación, paso a tablas, integridad y normalización. Todo ello construyendo, paso a paso, la base de datos de una tienda digital de videojuegos.

Resultado de aprendizaje 6 · Bases de Datos (0484) · CFGS DAM / DAW · IES Comercio · Logroño (La Rioja)

Resultado de aprendizaje¶

RA 6

Diseña modelos relacionales normalizados interpretando diagramas entidad/relación.

Estos son los criterios de evaluación del RA 6 y el apartado donde se trabaja cada uno. Verás las etiquetas CE 6x junto a los títulos de las secciones.

Criterio Qué se evalúa Dónde
CE 6a Se han utilizado herramientas gráficas para representar el diseño lógico. Apartados 2, 3 y 9
CE 6b Se han identificado las tablas del diseño lógico. Apartados 4 y 5

CE 6d Se han analizado las relaciones entre las tablas del diseño lógico. Apartado 5

CE 6g Se han aplicado reglas de normalización. Apartado 7
CE 6h Se han analizado y documentado las restricciones que no pueden plasmarse en el diseño lógico. Apartado 8

El hilo conductor: PixelVault¶

A lo largo de toda la unidad diseñamos la base de datos de PixelVault, una tienda digital (ficticia) que vende videojuegos para PC y consolas. Cada apartado añade una pieza: primero las entidades básicas, después la jerarquía de juegos de pago y free-to-play, luego las tablas, la normalización de un ticket de compra... Al final tendrás el diseño completo de una base de datos realista.

Herramientas de la unidad¶

Herramienta Para qué la usamos
Papel y lápiz Los primeros bocetos del diagrama E/R: es lo más rápido para pensar.
draw.io (diagrams.net) Dibujar diagramas E/R en notación Chen para entregar.
Oracle SQL Data Modeler Modelo lógico y relacional, y generación del script DDL para Oracle.
Oracle SQL Developer Ejecutar el script generado en Oracle Database XE (lo veremos a fondo en la UD 5).

Cómo usar estos apuntes

  • Usa el buscador (arriba a la derecha) para encontrar cualquier término.
  • Cambia entre modo claro y oscuro con el icono del sol o la luna: los diagramas se adaptan.
  • Los diagramas grandes se pueden desplazar en horizontal si la pantalla es estrecha.
  • Al final tienes ejercicios resueltos y una autoevaluación con las soluciones plegadas.
