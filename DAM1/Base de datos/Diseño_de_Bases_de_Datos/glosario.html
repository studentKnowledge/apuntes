Glosario de la UD 2¶

Los términos clave de la unidad, por orden alfabético.

Acción referencial
Lo que hace el SGBD con las filas que referencian a una fila que se borra: restringir el borrado, borrar en cascada (ON DELETE CASCADE) o poner la clave ajena a nulo (ON DELETE SET NULL).
Agregación
Construcción del modelo E/R ampliado que trata una relación, junto con sus entidades, como una entidad de nivel superior para poder relacionarla con otras. Se dibuja con un recuadro.
Anomalía
Problema que aparece en una tabla mal diseñada al insertar (no se puede guardar un dato sin otro), modificar (hay que cambiar el mismo dato en muchas filas) o borrar (se pierde información que no se quería borrar).
Atributo
Propiedad de una entidad o de una relación. En el modelo relacional, cada columna de una tabla.
Atributo compuesto
Atributo formado por otros atributos, como la dirección (calle, número, código postal...). Al pasar a tablas se sustituye por sus componentes.
Atributo derivado
Atributo cuyo valor se calcula a partir de otros datos, como la edad o la nota media. No se guarda en las tablas.
Atributo multivaluado
Atributo que puede tener varios valores para la misma ocurrencia, como los idiomas de un juego. Se dibuja con elipse doble y genera una tabla propia.
Cardinalidad de una relación
En el modelo E/R, los pares (mín, máx) que se escriben en cada extremo de una relación. En estos apuntes se usa el convenio del extremo opuesto: junto a la entidad B se indica cuántas ocurrencias de B se relacionan con una ocurrencia de A. Los máximos determinan el tipo: 1:1, 1:N o N:M.
Cardinalidad de una tabla
En el modelo relacional, número de filas que tiene una tabla en un momento dado.
Clave ajena (FK)
Columna o conjunto de columnas cuyos valores deben coincidir con los de la clave primaria (o alternativa) de otra tabla o de la misma. Implementa las relaciones.
Clave alternativa (UK)
Clave candidata que no se ha elegido como primaria. Sus valores no pueden repetirse; en Oracle se declara con UNIQUE.
Clave candidata
Conjunto mínimo de atributos que identifica cada fila de una tabla.
Clave primaria (PK)
Clave candidata elegida para identificar las filas. No puede repetirse ni contener nulos. Se subraya.
Clave subrogada
Identificador artificial, sin significado para el usuario (como id_jugador), que se usa como clave primaria porque no cambia nunca.
Dependencia funcional
Relación entre atributos X → Y que se cumple cuando cada valor de X determina un único valor de Y.
Dependencia parcial
Dependencia de un atributo respecto a una parte de una clave compuesta. Su ausencia define la 2FN.
Dependencia transitiva
Dependencia de un atributo respecto a la clave a través de otro atributo que no es clave (X → Z → Y). Su ausencia define la 3FN.
Desnormalización
Decisión consciente de dejar redundancia en una tabla normalizada para mejorar el rendimiento.
Diccionario de datos
Documento que acompaña al diagrama E/R con la lista completa de entidades, relaciones y atributos.
Discriminador
Atributo de una entidad débil por identificación que, junto con la clave de la entidad fuerte, identifica cada ocurrencia. También se llama clave parcial.
Dominio
Conjunto de valores válidos que puede tomar un atributo.
Entidad
Objeto, persona, concepto o suceso del mundo real del que interesa guardar información y que se puede distinguir de los demás. Se dibuja con un rectángulo.
Entidad débil
Entidad que depende de otra (la fuerte). Puede depender en existencia (no existe sin la fuerte) o en identificación (además, necesita la clave de la fuerte para identificarse).
Esquema relacional
Conjunto de tablas de una base de datos con sus columnas, claves primarias y claves ajenas.
Forma normal
Conjunto de condiciones que cumple una tabla. Las principales son 1FN (valores atómicos), 2FN (sin dependencias parciales), 3FN (sin dependencias transitivas) y FNBC (todo determinante es clave candidata).
Generalización
Proceso de reunir en un supertipo los atributos y relaciones comunes de varias entidades. El proceso inverso es la especialización.
Grado de una relación
En el modelo E/R, número de entidades que participan en una relación (reflexiva, binaria, ternaria). En el modelo relacional, número de columnas de una tabla.
Integridad de entidad
Regla que prohíbe que la clave primaria sea nula o se repita.
Integridad referencial
Regla que obliga a que cada valor de una clave ajena exista como clave primaria en la tabla referenciada, o sea nulo.
Jerarquía
Relación ES UN entre un supertipo y sus subtipos. Puede ser total o parcial, y exclusiva o solapada.
Modelo entidad/relación (E/R)
Modelo conceptual, propuesto por Peter Chen en 1976, que describe la realidad mediante entidades, atributos y relaciones.
Modelo relacional
Modelo lógico, propuesto por Edgar F. Codd en 1970, que organiza los datos en tablas (relaciones) enlazadas mediante claves.
Normalización
Proceso de descomponer tablas para que cumplan las formas normales y eliminar así la redundancia y las anomalías.
NULL
Marcador que indica ausencia de valor, porque es desconocido o no aplicable. No equivale a cero ni a cadena vacía.
Oracle SQL Data Modeler
Herramienta gratuita de Oracle para diseñar modelos lógicos y relacionales y generar el script DDL.
Participación
Indica si la relación es obligatoria (mínimo 1) u opcional (mínimo 0). Con el convenio del extremo opuesto, el mínimo escrito junto a B dice si toda ocurrencia de A tiene que estar relacionada con alguna B.
Propagación de clave
Forma de transformar una relación 1:N (o 1:1) sin crear tabla: la clave primaria de la entidad del lado 1 se copia como clave ajena en la tabla del lado N. También se usa para formar la clave de las entidades débiles.
Relación (modelo E/R)
Asociación entre entidades. Se dibuja con un rombo.
Relación (modelo relacional)
Tabla. Conjunto de tuplas con los mismos atributos.
Relación reflexiva
Relación de una entidad consigo misma, como es_amigo_de. Necesita roles en cada extremo.
Relación ternaria
Relación en la que participan tres entidades a la vez.
Restricción no representable
Regla de negocio que no se puede expresar en el diagrama E/R ni con las claves del esquema relacional, y que hay que documentar aparte.
Tupla
Fila de una tabla.
